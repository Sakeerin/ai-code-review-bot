# Code of Conduct

We want a welcoming place to collaborate on AI Review Bot. These expectations
apply to project issues, pull requests, reviews, and other project spaces.

- Treat people with respect, regardless of background, identity, experience,
  language, or technical ability.
- Give actionable feedback about ideas and code. Explain disagreements without
  personal attacks, harassment, discrimination, threats, or sexualized conduct.
- Respect privacy. Do not publish another person's personal information, private
  messages, credentials, or source code without permission.
- Keep discussion relevant and avoid spam, impersonation, and disruptive behavior.
- Assume mistakes can be corrected. Accept reasonable feedback and respect
  maintainers' moderation decisions.

Maintainers may edit or remove inappropriate content, restrict participation,
or block accounts to protect the community. Responses should consider context,
severity, and repeated behavior.

To report a conduct concern, contact a maintainer through an available private
channel. If no private channel is available, request one in an issue without
publishing personal details. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
